# Herramientas del curso

No son parte de la app. Las usa la guía «El harness de un agente de IA».

- `npm run romper -- <caso>`: rompe una cosa conocida, siempre igual. Sin caso, enseña la lista. Se deshace con `git checkout .`.
- `npm run paso -- NN`: dice con ✅ y ❌ si lo del paso NN está hecho. Comprueba lo que hace cada pieza, no cómo está escrita.
